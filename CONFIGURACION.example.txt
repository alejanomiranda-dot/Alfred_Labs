Configuración de Taller de Vero

La clave de OpenAI se guarda solamente en .env.local, en la raíz del proyecto.
Nombre de variable: OPENAI_API_KEY.
No adjuntar ni copiar ese archivo al chat, a repositorios o a paquetes públicos.
Usar el flujo seguro de OpenAI Developers para crear o reemplazar la clave.

Arranque: doble clic en Iniciar taller.cmd.
Dirección local: http://127.0.0.1:5173/
Si el puerto está ocupado, usar el taller ya iniciado o cerrar su ventana anterior.
Verificación de cambios: npm run verify.

La aplicación web publicada conserva herramientas de diseño y exportación.
El asistente con IA utiliza el servidor local y requiere conexión a Internet.
El envío a impresora se realiza desde Bambu Studio después de revisar el laminado.
